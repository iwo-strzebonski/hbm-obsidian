Modyfikatory sumują się - zaklęcie otrzymuje każdy modyfikator, którego opis do niego pasuje (np. natychmiastowa Kula Ognia rzucana na jeden cel z T=6 dostaje jednocześnie "Natychmiastowy", "Pojedynczy cel", "Trudny do rzucenia" oraz "Dodatkowy Stan" za Podpalenie). Modyfikatory oznaczone jako "za każdy" liczy się tyle razy, ile razy dana cecha występuje w zaklęciu.

### Czas działania, cele i trudność

| Modyfikator        | Wartość | Opis                                |
| ------------------ | ------- | ----------------------------------- |
| Natychmiastowy     | -1.0    | Efekt jednorazowy, bez utrzymywania |
| Krótkotrwały       | -0.5    | Efekt utrzymuje się tylko przez 1 rundę |
| Pojedynczy cel     | -0.8    | Działa tylko na jeden cel (w tym na samego maga lub trzymany przedmiot) |
| Łatwy do rzucenia  | -0.5    | Niska trudność (T=3-4); nowo tworzone zaklęcia nie mogą mieć T niższej niż 4 |
| Obszarowy          | +0.5    | Działa na obszar lub wiele celów    |
| Trudny do rzucenia | +0.5    | Wysoka trudność (T=6)               |
| Wysokie wymagania  | +0.8    | Wymaga 3+ sukcesów                  |

### Siła i dodatkowe efekty

| Modyfikator                | Wartość | Opis |
| -------------------------- | ------- | ---- |
| Ignoruje Pancerz           | +1.0    | Obrażenia (lub inny efekt) pomijają zwykły Pancerz celu |
| Przebija magiczną ochronę  | +1.0    | Zaklęcie przełamuje osłony (każde dwa punkty obrażeń wyłączają punkt Runicznego Pancerza, a przeciwko Magicznej Osłonie obrażenia liczą się podwójnie) albo całkowicie pomija Runiczny Pancerz i Magiczną Osłonę |
| Dodatkowy Stan lub efekt   | +0.5 za każdy | Drugorzędny efekt towarzyszący głównemu: nałożenie Stanu (np. Podpalony, Przewrócony, Oszołomiony, Przerażony, Zauroczony, Oślepiony), Trudny Teren, obniżenie Pancerza, odwet na napastniku, natychmiastowe zniszczenie słabego Nieumarłego itp. |
| Odebranie Akcji            | +1.0    | Cel traci Akcje, nie może rzucać zaklęć, zostaje Unieruchomiony albo traci przytomność |
| Premia lub kara do Testów  | +0.2 za każdy | Każda dodatkowa (lub odebrana) kość, każdy Sukces oraz każdy stopień, o który zmienia się Trudność Testów lub ataków |
| Wiele osobnych efektów     | +1.0    | Jedno rzucenie tworzy kilka niezależnych efektów naraz (np. osobne Tarcze dla kilku celów) |
| Darmowe rzucenie           | +1.0    | Zaklęcie pozwala rzucić inne zaklęcie bez wydawania Many albo daje dodatkową Akcję |
| Ograniczony efekt          | -1.0    | Drobny efekt użytkowy o znikomym wpływie na walkę i fabułę (np. światło, przedmiot do 1 kg, 1 litr wody, duch niezdolny do wpływania na materię) |
| Tylko poza walką           | -1.0    | Zaklęcia nie można rzucić w trakcie walki albo jego Czas rzucania wynosi co najmniej 1 minutę |
| Rytualny/Specjalny         | +1.5    | Wyjątkowe efekty łamiące zwykłe zasady gry - niewidzialność, natychmiastowe przeniesienie się (np. Przeskok, Teleportacja), przemiana ciała, przywołanie istoty, rozmowa z umarłymi, wpływ na Manę lub Zapał, usunięcie choroby - a także efekty legendarne |

### Minimalny koszt zaklęć ofensywnych

Niezależnie od wyniku wzoru zaklęcie z kategorii Obrażenia, którego efekt liczbowy ma Potęgę Efektu co najmniej Standardową, kosztuje nie mniej niż:

| Potęga Efektu | Minimalny koszt many |
| ------------- | -------------------- |
| Standardowa   | 2                    |
| Wzmocniona    | 3                    |
| Potężna       | 4                    |

Dzięki temu łatwe w rzucie zaklęcie zadające pełną wartość Umiejętności Zdolności Magiczne nie może kosztować zaledwie 1 punktu many, nawet jeśli suma modyfikatorów zepchnęłaby jego koszt poniżej tej wartości.
