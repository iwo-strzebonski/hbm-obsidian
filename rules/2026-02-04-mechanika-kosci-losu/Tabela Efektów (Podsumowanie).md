### Kości Nieszczęścia (wpływają na przeciwników)

| Kość | Ładunki | Nazwa | Efekty do wyboru |
|:----:|:-------:|-------|------------------|
| ⚀ | 1 | **Pięść Fatum** | **Katastrofalny błąd:** Wszystkie kości następnego Testu lub Ataku celu liczone są jako porażki |
| | | | **Przerwanie zaklęcia:** Natychmiast przerywasz rzucanie dowolnego zaklęcia w zasięgu wzroku; cel traci akcję i zasoby (Mana, komponenty); nie działa na efekty Nieprzerywalne ani Superzaklęcia |
| | | | **Załamanie losu:** Cel w następnej Turze nie może wykonać Akcji ani Ruchu (zachowuje darmową Akcję Natychmiastową); raz na walkę na cel; nie działa na Postacie Unikalne |
| ⚁ | 2 | **Cień Przekleństwa** | **Utrata równowagi:** Cel zostaje Przewrócony i musi poświęcić Ruch na wstanie |
| | | | **Zaćmienie umysłu:** Cel musi ponownie zadeklarować akcję; jeśli rzucał zaklęcie, traci koncentrację |
| | | | **Pęknięcie obrony:** Do końca następnej Tury celu: cel traci 2 punkty Pancerza, a następny atak, który go trafi, zadaje podwójne Obrażenia (mnożenie przed odjęciem Runicznego Pancerza, Osłony i Pancerza) |
| ⚂ | 3 | **Szepty Niepewności** | **Chwila wahania:** Cel w następnej Turze może wykonać tylko Ruch albo Akcję |
| | | | **Rozkojarzenie:** Następny Test lub Atak celu jest o dwa Stopnie trudniejszy |
| | | | **Złowróżbny cień:** Cel wykonuje Test Dusza (Determinacja) 5:2; porażka = Przerażony do końca walki, nie może zbliżyć się na mniej niż 5 m |

### Kości Fortuny (wpływają na postać)

| Kość | Ładunki | Nazwa | Efekty do wyboru |
|:----:|:-------:|-------|------------------|
| ⚃ | 4 | **Błogosławieństwo Losu** | **Szczęśliwy traf:** Dodaj +2 Sukcesy do właśnie wykonanego Testu (po zobaczeniu wyniku) |
| | | | **Ochrona fortuny:** Zignoruj Obrażenia z jednego ataku lub źródła do wysokości połowy Maks. Żywotności (w górę) |
| | | | **Szybka reakcja:** Natychmiast wykonaj dodatkowy Ruch poza kolejnością inicjatywy |
| ⚄ | 5 | **Uśmiech Fortuny** | **Podmuch wiatru:** Dodaj +1 Sukces do właśnie wykonanego Testu |
| | | | **Zrządzenie losu:** Przerzuć wszystkie kości w Teście; musisz zaakceptować nowy wynik |
| | | | **Chwila wytchnienia:** Odzyskaj 5 Punktów Żywotności lub 3 Many |
| ⚅ | 6 | **Iskra Szczęścia** | **Odrobina szczęścia:** +1 Sukces do Testu; jeśli Test i tak by się powiódł, następny Test w scenie jest o jeden Stopień łatwiejszy |
| | | | **Przeczucie:** Poznaj do 3 informacji o zagrożeniach w promieniu 30m (pułapki, zasadzki, wrogowie, ich liczba/kierunek) |
| | | | **Drobna fortuna:** Znajdź użyteczny przedmiot w otoczeniu (lina, broń prosta, Eliksir Zdrowia (mały) lub rzecz do 250 zł) - musi być realnie przydatny |
