### Kości Nieszczęścia (wpływają na przeciwników)

| Kość | Ładunki | Nazwa | Efekty do wyboru |
|:----:|:-------:|-------|------------------|
| ⚀ | 1 | **Pięść Fatum** | **Katastrofalny błąd:** Cel automatycznie ponosi krytyczną porażkę na następnym Teście lub ataku |
| | | | **Przerwanie zaklęcia:** Natychmiast przerywasz rzucanie dowolnego zaklęcia w zasięgu wzroku; cel traci akcję i zasoby |
| | | | **Załamanie losu:** Cel traci całkowicie następną turę (brak akcji i reakcji); raz na walkę na cel |
| ⚁ | 2 | **Cień Przekleństwa** | **Utrata równowagi:** Cel zostaje Powalony; musi poświęcić akcję ruchu na wstanie; prowokuje ataki okazyjne |
| | | | **Zaćmienie umysłu:** Cel musi ponownie zadeklarować akcję; jeśli rzucał zaklęcie, traci koncentrację |
| | | | **Pęknięcie obrony:** Cel traci 2 punkty Pancerza i ma Podatność na następny atak (×2 obrażenia) do końca Twojej tury |
| ⚂ | 3 | **Szepty Niepewności** | **Chwila wahania:** Cel traci 1 Akcję w następnej turze (tylko ruch lub akcja główna) |
| | | | **Rozkojarzenie:** Cel ma Utrudnienie (×2 próg Trudności) na następny Test lub atak |
| | | | **Złowróżbny cień:** Cel wykonuje Test Woli (Dusza + Opanowanie, TS 5:2); porażka = Przestraszony postacią do końca walki |

### Kości Fortuny (wpływają na postać)

| Kość | Ładunki | Nazwa | Efekty do wyboru |
|:----:|:-------:|-------|------------------|
| ⚃ | 4 | **Błogosławieństwo Losu** | **Szczęśliwy traf:** Dodaj +3 Sukcesy do właśnie wykonanego Testu (po zobaczeniu wyniku) |
| | | | **Ochrona fortuny:** Zignoruj całość obrażeń z jednego ataku (łącznie z efektami jak trucizna, podpalenie) |
| | | | **Szybka reakcja:** Natychmiast wykonaj dodatkową Akcję Ruchu lub Reakcję poza kolejnością inicjatywy |
| ⚄ | 5 | **Uśmiech Fortuny** | **Podmuch wiatru:** Dodaj +2 Sukcesy do właśnie wykonanego Testu |
| | | | **Zrządzenie losu:** Przerzuć wszystkie kości w Teście; musisz zaakceptować nowy wynik |
| | | | **Chwila wytchnienia:** Odzyskaj 2 Punkty Żywotności lub 3 Punkty Magii |
| ⚅ | 6 | **Iskra Szczęścia** | **Odrobina szczęścia:** +1 Sukces do Testu; jeśli Test i tak by się powiódł, zyskujesz Przewagę na następny Test w scenie |
| | | | **Przeczucie:** Poznaj do 3 informacji o zagrożeniach w promieniu 30m (pułapki, zasadzki, wrogowie, ich liczba/kierunek) |
| | | | **Drobna fortuna:** Znajdź użyteczny przedmiot w otoczeniu (lina, broń prosta, mikstury do 50 zł) - musi być realnie przydatny |
